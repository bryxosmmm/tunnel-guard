## Состояния и отказ среды

Проверен реальный узел без входа при `use_sim_time=true` и замороженном `/clock`. Его wall-clock watchdog опубликовал `unknown`, пустой PointCloud2, MarkerArray с `DELETEALL`, `attention_required=true`, NaN distance, `measurement_timestamp_ns=null`, `result_age_s=null`; по одному сообщению на каждый топик. Это **старт без свежего скана**, а не потеря уже заполненной сцены.

Попытка штатного rate-1 replay отправила все 201 исходных PointCloud2 за 20,29 с. На первом callback процесс детектора завершился `SIGILL` при импорте Open3D 0.19.0 под amd64-эмуляцией, до выдачи первого результата. Обработано 0. Это отказ окружения, не измерение пропусков при перегрузке. Нативный Linux/arm64 образ не собран: pinned Open3D 0.19.0 отсутствует для Python 3.10/arm64. Оба отказа и сырые логи сохранены.

Из-за этого полный live callback p50/p95/p99, приём и пропуски при перегрузке, возраст результата по сопоставимым часам, очистка после заполненной сцены, восстановление по новым timestamps и RViz GUI **не проверены**. Не считаем `sensor timestamp` и host clock сопоставимыми. `result_age_s` остаётся null. Для закрытия нужны Linux/amd64 с поддержкой pinned Open3D (целевой i7), ROS Humble, исходный bag и графическая сессия; команды — в [DELIVERY_DEMO.md](../docs/DELIVERY_DEMO.md) и [TARGET_ACCEPTANCE.md](../docs/TARGET_ACCEPTANCE.md).
