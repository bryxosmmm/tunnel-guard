# Tunnel Guard — результаты итерации 2026-09-19

## Что изменено

- Density-сегментация строит точный граф соседства пакетами по локальному радиусу вместо запроса максимального радиуса для всех точек.
- В каждый кластер добавлен `rail_relative_support`: медиана поперечной координаты, диапазон высоты над головкой рельса и неопределённость локальной оси пути.
- Результат геометрической классификации повторно используется для range-observability; лишний расчёт удалён.
- Конфигурация валидируется до запуска: extrinsics, диапазоны, bins, slope limits, segmentation method и целочисленные пороги.
- В диагностику добавлена оценка высоты сенсора от локального track bed с явным указанием, что это не surveyed extrinsic.
- SUSTechPOINTS переведён в локальный viewer-only режим: localhost, без TensorFlow и отсутствующей auto-annotation модели.
- Добавлены изолированные experiment runner, HTML/CSV-визуализация и Dockerfile для Ubuntu 22.04 / ROS 2 Humble.
- Пять первичных статей и исходники FreeDOM сохранены в `ALL WE KNOW /research/`; URL, SHA-256, лицензии и ревизии записаны в `SOURCES.json`.

## Границы результата

- Текущий p50 выше периода 100 мс для 10 Гц.
- 4 clearance-кандидата не являются четырьмя доказанными препятствиями.
- Без исчерпывающей разметки real-data precision, recall и дальность детекта не измерены.
- Dockerfile не собран на текущей машине из-за отсутствия Docker engine.
